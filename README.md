Co się dzieje na ESPCI 2025?
Ta aplikacja webowa pozwala przeglądać harmonogram konferencji ESPCI 2025, która odbywa się w dniach 12-14 czerwca 2025 roku. Użytkownik może wybrać datę z kalendarza, aby zobaczyć prezentacje i sesje posterowe zaplanowane na dany dzień.
Funkcjonalności
Wybór Daty: Łatwy wybór daty konferencji (12-14 czerwca 2025) za pomocą pola daty.
Wyświetlanie Wydarzeń: Po wybraniu daty aplikacja wyświetla listę prezentacji i sesji posterowych.
Szczegóły Wydarzeń: Dla każdej prezentacji i posteru wyświetlane są takie informacje jak: tytuł, nazwisko prelegenta, afiliacja, kraj, sesja, czas i lokalizacja.
Brak Wymaganego Logowania: Aplikacja działa bez konieczności logowania się, co zapewnia łatwy dostęp dla każdego.
Technologie
Aplikacja została zbudowana przy użyciu następujących technologii:
Frontend:
React: Biblioteka JavaScript do budowania interfejsów użytkownika.
HTML/CSS: Podstawa struktury i stylizacji strony.
Tailwind CSS: Framework CSS do szybkiego i responsywnego stylizowania.
JavaScript: Język programowania do obsługi logiki frontendu.
Jak uruchomić lokalnie
Aby uruchomić tę aplikację na swoim komputerze, wykonaj następujące kroki:
Sklonuj repozytorium:
git clone [LINK_DO_TWOJEGO_REPOZYTORIUM]
cd [NAZWA_TWOJEGO_REPOZYTORIUM]


Zainstaluj zależności:
npm install
# lub
yarn install


Uruchom aplikację:
npm start
# lub
yarn start


Aplikacja zostanie uruchomiona w trybie deweloperskim. Otwórz http://localhost:3000 w przeglądarce, aby ją zobaczyć.
Struktura Plików
public/index.html: Główny plik HTML.
src/App.js: Główny komponent React zawierający logikę i dane aplikacji.
package.json: Definicje projektu i zależności.
.gitignore: Plik ignorujący niepotrzebne pliki w repozytorium Git.
README.md: Ten plik.
